# TCL RC802A

图稿、22 个按键及原始 HID 采集位于 `public/device-descriptors/tcl-rc802a.svg`；来源为 `feat/leo/proto` 的设备草稿。语音触发是九字节报告 `01 00 00 AD 00 00 00 00 00`，释放为同布局零值。

## 录音与传输

- 仅支持按住模式（`trigger-modes="hold"`）：按下发送 `EB 01`，抬起发送 `EB 00`。遥控器固件在松开物理麦克风键时自行停止 `EC` 音频采集，不支持点击切换或脱离物理按键的界面手动开始录音；已保存实例在加载与保存时统一收敛为 `hold`。
- 禁用设备、停止或断开会话沿用现有 HID 录音控制，录音中停止时发送 `EB 00`；失败不提前提交录音状态。
- 每实例维护独立分片、录音和解码状态，Windows 使用该实例的 Quarbor HID 通道；macOS 使用同实例独占 HID 会话，PCM 注入现有虚拟麦克风输出。

每个音频报告包含 21 字节：`EC seq_lo seq_hi fragment unused payload[16]`。同组的 0/1/2 分片依次重组为 `report0[5:21] + report1[5:21] + report2[5:13]`，得到 40 字节 ICO 帧；第三片余下 8 字节只保留为尾部信息，不参与解码。不同组、缺片、乱序、错误长度均不拼成音频；从新片零恢复。驱动重复报告不重复解码。

## ICO 解码

依据用户提供的 `tmp/ICO音频解码算法与验证.md`：40 字节按 20 个小端 u16 读取，四组索引 `(4,16,9)`、`(8,3,11)`、`(2,6,18)`、`(7,13,17)` 执行 `(a,b,c) ← (c,a,b)`，各字 XOR `0x0416`，按大端字重写 G.722.1 码流。

复用仓库已有 `libsiren` 的 headerless G.722.1 模式（16 kbit/s、16 kHz），每帧输出 320 个单声道 i16 采样，清除每个采样最低两位。解码状态跨帧复用，在每段录音开始、停止、报告缺口或解码失败后重置；不填充假 ICO 帧。

现有 libsiren 为浮点实现。说明文件使用定点 libg7221 与固件逐采样比对得到的零差异结论，不自动适用于本适配器；本次沿用项目现有解码依赖，没有移植固件二进制或新增运行时 DLL。

## 验证边界

自动测试使用 SVG 中真实按键采集和由现有 G.722.1 编码器生成的合成音频，覆盖 EB 控制、完整 EC→ICO→PCM、连续帧状态、输出对齐、重复、长度错误、混组及录音重置，并检查 Windows 音频队列路由。尚未采集 RC802A 实物 EC 语音，未验证实机语音质量或 macOS 原生运行。
