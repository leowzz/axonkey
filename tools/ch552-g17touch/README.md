# G17 Touch (`最丐17+4TPRO机械键盘`) CH552G Raw HID 固件

面向基于 `CH552G` + `SL2.1A` USB Hub 的 17 键机械 + 4 段式电容触摸滑条小键盘的 Axonkey 免驱 Vendor Raw HID 固件（`0x1209:0xA017`，`Usage Page 0xFF60 / Usage 0x01`）。

## 相对原厂 `Ver202` 固件的关键改进

1. **彻底解决 USB 挂起睡死问题**：
   - 不调用 `PCON |= 0x02`（Power-Down 深度休眠），收到 `UIF_SUSPEND` 时仅熄灭 RGB 背光并置位状态标记，按键与触控扫描保持全天候响应，Windows USB 选择性暂停不会卡死设备。
2. **32 位按键位图独立消抖上报**：
   - 协议层采用 `u32` 位图逐槽独立 10ms 消抖上报（不受传统 USB 6KRO 报文长度限制）；但**硬件电路本身并非全键无冲**，多键同按受查理复用与对地直连拓扑限制（详见下方「硬件电路与多键冲突边界」）。
3. **4 段电容滑条消歧义与线性定位引擎（`H1`: `TIN2/4/5/1`）**：
   - 物理从上到下通道：`T1=TIN2(P1.4/ch3)`、`T2=TIN4(P1.6/ch5)`、`T3=TIN5(P1.7/ch6)`、`T4=TIN1(P1.1/ch2)`。
   - **连续上滑 / 下滑（`SWIPE_UP` / `SWIPE_DOWN`）**：总电容跨缝保持不断触，支持长按后直接转入滑动、折返零死区即时换向与 `12ms/8ms` 高速步进脉冲。
   - **线性精细坐标（`slider_pos: 0..1000`）+ 接触态（`TOUCH_CONTACT`）**：`Input Report 0x01` 的 `bytes 6..7` 实时上报 `0..1000`（`0.1%` 分辨率，每变化 `0.5%` 推送），手指抬离瞬间冻结末次有效坐标，可直接支撑「滑动预览列表、松手确认选择」交互。
   - **4 段点按 / 按住（`T1..T4`）**：短触抬起发射点按脉冲，原地长按保持对应段位激活，滑动过程中不误触段位点按。
   - **WS2812 串扰与异常帧隔离**：刷新 `P1.5/MOSI` 灯珠期间及之后 3ms 跳过采样，硬件层自动丢弃 `bTKD_CHG` 与 `< 1500` 的异常跳变帧。

## HID 报文约定

| Report ID | 方向 | 线长 | 结构 |
| --- | --- | --- | --- |
| `0x01` | Input | 8 B | `[0x01, key_bitmap: u32 LE (bit0..16=K01..K17, bit20..23=T1..T4, bit24=SWIPE_UP, bit25=SWIPE_DOWN, bit26=TOUCH_CONTACT), flags, slider_pos: u16 LE (0..1000)]` |
| `0x02` | Output | 64 B | `op=0x01` 设置 RGB 背光 `[0x02, 0x01, mode, r, g, b, brightness]`；`op=0x02` 调节触摸灵敏度 `[0x02, 0x02, press_thresh, release_thresh, swipe_step]` |
| `0x10` | Feature | 16 B | 能力报告 `[0x10, ver=2, keys=23, caps=0x03 (bit0=linear_slider, bit1=rgb_led), press_thresh, swipe_step, brightness, flags, ...]` |
| `0x11` | Feature | 8 B | 当前状态快照 `[0x11, key_bitmap: u32 LE, flags, seq, 0]` |
| `0x12` | Feature | 32 B | 硬件原始诊断快照（`idle_p3`、`drv_p3[5]`、`matrix_stable`、4 通道触摸原始值与基线、跳过计数等） |

## 硬件电路与多键冲突边界

根据原厂硬件原理图（`最丐17+4TPRO机械键盘 V0.1`）及量产实机 PCB 实测，该键盘**硬件上不是全键无冲（NKRO）设计**：

### 1. 矩阵拓扑（原理图 vs 量产实机 PCB）

- **主控与供电**：`U3 (CH552G)` 由 `U1 (HT7533)` 降压至 **`VCC = 3.3V`** 供电，矩阵总线 `K1`–`K5`（`P3.0, P3.1, P3.2, P3.4, P3.3`）各接一颗 **`1kΩ` 强上拉电阻**（`R6`–`R10`）至 `3.3V`。
- **原理图（`V0.1`）**：虽然 `S1`–`S20` 每颗轴串联了 `LL4148` 二极管（`D1`–`D20`），但并非标准「行驱动、列采样分离」矩阵（17 键至少需 `4+5=9` 个 GPIO），而是共用 5 根 IO 的**查理复用（Charlieplexing）矩阵**——每个引脚同时承担轴体阴极驱动端与其他轴体二极管阳极采样端；第 17 颗数字键 `5`（`S21`）直接跨接在 **`RST`（Pin 6）与 `VCC`** 之间。
- **量产实机 PCB**：未接线使用 `K4 (P3.4)`，17 颗机械键实际分配为：
  - **12 颗查理复用键**（`K1 / K2 / K3 / K5` 互扫）：
    - `drv = K1 (P3.0)`：`K2 (Num)`、`K3 (/)`、`K5 (*)`
    - `drv = K2 (P3.1)`：`K1 (-)`、`K3 (7)`、`K5 (9)`
    - `drv = K3 (P3.2)`：`K1 (+)`、`K2 (1)`、`K5 (3)`
    - `drv = K5 (P3.3)`：`K1 (Enter)`、`K2 (0)`、`K3 (.)`
  - **4 颗对 `GND` 直连键**：`K1 → GND (8)`、`K2 → GND (4)`、`K3 → GND (6)`、`K5 → GND (2)`
  - **1 颗独立 `RST` 键**：`RST → VCC (5)`（通过 `CLOCK_CFG & bRST` 读取）

### 2. 多键同按时的三类物理现象

1. **查理复用同向两级串联导通 → 鬼键或临界抖动**：
   - 当同时按下任意两个首尾相接的查理复用键（如 `Num (K1←K2)` + `7 (K2←K3)`）时，拉低 `K1 (≈0.08V)` 会使两颗 `LL4148` 顺向串联导通（`VCC → R8 → K3 → D6 → K2 → D1 → K1`）。
   - 单键导通时采样脚约为 `0.70V`；两级二极管串联时 `K3 ≈ 0.08V + 0.62V + 0.58V ≈ 1.28V`，恰好落入 `3.3V` 供电下 `CH552G` `P3` 口输入翻转阈值（约 `1.3V`–`1.5V`）的低电平/临界区，导致误触发第 3 颗键 `/`（`K1←K3`）鬼键或电平抖动。
2. **`8 / 4 / 6 / 2` 对地直连 → 必现整列吞键与变键（软件不可区分）**：
   - **吞键（电平掩蔽）**：按住某颗对地键会将对应总线物理钳死在 `0V`，导致以该线作为采样脚的 3 颗键彻底无法检测：
     - 按住 `8 (K1→GND)`：`-`、`+`、`Enter` 失灵
     - 按住 `4 (K2→GND)`：`Num`、`1`、`0` 失灵
     - 按住 `6 (K3→GND)`：`/`、`7`、`.` 失灵
     - 按住 `2 (K5→GND)`：`*`、`9`、`3` 失灵
   - **变键（引脚真值表完全等价）**：按住 `8 (K1=0V)` 再按 `Num (K1←K2)` 时，`K2` 经 `D1` 被直接拉低，空闲态与各驱动态下 5 根引脚电平与同时按下 `8 + 4` **100% 相同**，导致 `8 + Num` 变为 `8 + 4`（`8 + /` 变 `8 + 6`、`8 + *` 变 `8 + 2`，`4 / 6 / 2` 同理）。
3. **`1kΩ` 强上拉灌电流抬升低电平**：
   - 同一驱动线同时按住多键时，单个 `P3` 引脚灌电流可达 `11mA`–`14mA`，`3.3V` 下输出低电平 `VOL` 抬升至 `0.3V`–`0.4V` 以上，进一步压缩噪声容限。

### 3. 组合键配置建议

- **正交无冲通道**：数字 **`5`（`S21`，独立走 `RST → VCC`）** 与右侧 **4 段电容触摸滑条（`T1`–`T4`）** 和 `K1`–`K5` 矩阵完全电气隔离，适合作为「长按修饰键 + 其他单键」组合层的触发键。
- **避免用作修饰键**：不要将 **`8`、`4`、`6`、`2`** 设为需要长按配合其他按键的修饰键。

## 构建与单测

```sh
cd tools/ch552-g17touch
make test   # 使用 gcc 运行主机端引擎单测
make        # 使用 SDCC 编译生成 .build/g17touch.hex
```

烧录到实机时打开 `WCHISPTool`（芯片选 `CH552`、`P3.6` 下载，**保持「使能 RST Pin 作为手工复位输入引脚」未勾选**），短接右上角 `S0` 方形/圆形焊盘上电后选择 `.build/g17touch.hex` 下载。
