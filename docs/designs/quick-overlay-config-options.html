入口直挂「快捷交互窗」行为 · 独立数据 · 仅单击拖拽组合
为什么旧版快捷配置显得繁琐？
旧版 · 复用顶层 Profile
  • 需在「关联配置」下拉框区分「快捷交互配置」与「其他配置」，心智负担重
  • 点「编辑按键」会跳离当前常规配置，顶部出现黄色横幅容易迷失
  • 编辑器与预览窗同时出现 双击 / 长按 泳道，而交互窗本应单次直出
新版 · 独立配置附属在行为上
  • 「快捷交互窗」行为自带名称、单击速览与「配置交互窗按键」入口
  • 顶层配置列表不再混入「快捷配置」，改完即回原按键与原配置
  • 专用配置器彻底隐藏双击/长按，保留完整的拖拽 + 多步组合 + 工具箱
