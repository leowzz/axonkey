# Hisense RCF3B65 图稿交接

状态：草稿 `draft`（运行时资源为 `public/device-descriptors/hisense-rcf3b65.svg`，输入绑定 `captured`）。图稿：[hisense-rcf3b65.svg](hisense-rcf3b65.svg)。品牌 Hisense、型号 RCF3B65 及硬件匹配规则由用户提供；几何与键帽图案依据正面实拍制作。

## 身份匹配

完整原始规则：`DEV_VID&01109B_PID&3837`

| 条件             | 值                                             |
| ---------------- | ---------------------------------------------- |
| Windows 硬件标识 | `DEV_VID&01109B_PID&3837`                      |
| 厂商 / 产品标识  | VID `0x01109B`（16 位 `0x109B`），PID `0x3837` |

草稿 SVG 的 `ak:pending-identity` 原样保留 `DEV_VID&01109B_PID&3837`；运行时描述器通过 `ak:identity` 匹配蓝牙 HID 节点。

## 图稿与输入

设备 ID 为 `hisense-rcf3b65`。下表的后缀均加 `hisense-rcf3b65.` 构成完整稳定输入 ID。

| 视图 / 位置        | 稳定 ID 后缀                  | 报文分组与字段                                              | 图案或含义                                   |
| ------------------ | ----------------------------- | ----------------------------------------------------------- | -------------------------------------------- |
| 正面顶部居中       | `power`                       | `0x01` 九字节 `offset=3`：`0x66`                            | 电源图标                                     |
| 正面左上、右上     | `input`、`pointer`            | `0x01` 九字节 `0xBB`、`0x6F 0x6A` 九字节 `offset=2`：`0x01` | 信号源（带入框箭头）、指向（圆环与光标箭头） |
| 正面中上偏下大圆键 | `ai`                          | `0x01` 九字节 `offset=3`：`0xA5`                            | `AI` 字样                                    |
| 正面左中、右中     | `tv`、`shortcut`              | `0x01` 九字节 `offset=3`：`0xB0`、`0x94`                    | 看电视（天线电视框）、快捷（右上纸飞机箭头） |
| 正面金色方向环     | `up`、`right`、`down`、`left` | `0x01` 九字节 `offset=3`：`0x52`、`0x4F`、`0x51`、`0x50`    | 四个不重叠环形扇区                           |
| 方向环中央         | `confirm`                     | `0x01` 九字节 `offset=3`：`0x28`                            | 独立圆形确认键                               |
| 环下左上、右上     | `back`、`home`                | `0x01` 九字节 `offset=3`：`0x71`、`0xE3`                    | 返回、主页                                   |
| 环下居中圆键       | `voice`                       | `0x01` 九字节 `offset=3`：`0xDF`                            | 麦克风图标                                   |
| 环下左下、右下     | `settings`、`menu`            | `0x01` 九字节 `offset=3`：`0xEF`、`0x72`                    | 设置（齿轮）、菜单（三横线方框）             |
| 底部横向长条左、右 | `volumeDown`、`volumeUp`      | `0x01` 九字节 `offset=3`：`0x81`、`0x80`                    | 音量减（`−`）、音量加（`+`）                 |

共 18 个正面输入，无侧键。普通按键走 `01 00 00 XX 00 00 00 00 00` 九字节状态组，`pointer` 走独立的 `6F 6A XX 00 00 00 00 00 00` 九字节状态组；HID Usage Page 未从硬件描述表确认，保持 `original="false"`。

实拍照片未完整拍到机身最底端圆角，图稿在横向音量键下方留适量握持边距裁切；底部直线为裁切边界，不代表实际机身底端。
