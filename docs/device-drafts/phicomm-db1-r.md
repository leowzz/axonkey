# 斐讯 DB1-R 图稿交接

状态：草稿 `draft`（运行时资源为 `public/device-descriptors/phicomm-db1-r.svg`，输入绑定 `captured`）。图稿：[phicomm-db1-r.svg](phicomm-db1-r.svg)。品牌斐讯（PHICOMM）、型号 DB1-R 及硬件匹配规则由用户提供；几何与键帽图案依据正面实拍制作并校正俯拍透视。

## 身份匹配

完整原始规则：`DEV_VID&01005D_PID&0001`

| 条件             | 值                                             |
| ---------------- | ---------------------------------------------- |
| Windows 硬件标识 | `DEV_VID&01005D_PID&0001`                      |
| 厂商 / 产品标识  | VID `0x01005D`（16 位 `0x005D`），PID `0x0001` |

草稿 SVG 的 `ak:pending-identity` 原样保留 `DEV_VID&01005D_PID&0001`；运行时描述器通过 `ak:identity` 匹配蓝牙 HID 节点。

## 图稿与输入

设备 ID 为 `phicomm-db1-r`。下表的后缀均加 `phicomm-db1-r.` 构成完整稳定输入 ID。实机采集中已移除无蓝牙 HID 报文的红外 `TV` 键，保留 12 个蓝牙正面按键。

| 视图 / 位置          | 稳定 ID 后缀                  | 报文分组与字段                                                       | 图案或含义                            |
| -------------------- | ----------------------------- | -------------------------------------------------------------------- | ------------------------------------- |
| 正面第一排左侧       | `ottPower`                    | `0x01` 九字节 `offset=3`：`0x66`                                     | `OTT` 红色电源键                      |
| 正面方向环           | `up`、`right`、`down`、`left` | `0x01` 九字节 `offset=3`：`0x52`、`0x4F`、`0x51`、`0x50`             | 四个不重叠环形扇区                    |
| 方向环中央           | `confirm`                     | `0x01` 九字节 `offset=3`：`0x28`                                     | `OK` 圆形确认键                       |
| 环下第一排左、中、右 | `back`、`voice`、`volumeUp`   | `0x02` 三字节 `0x0224`、`0x01` 九字节 `0x3E`、`0x02` 三字节 `0x00E9` | 返回、橙色麦克风语音键、音量加（`+`） |
| 环下第二排左、中、右 | `home`、`menu`、`volumeDown`  | `0x02` 三字节 `offset=1 width=16`：`0x0223`、`0x0040`、`0x00EA`      | 主页、菜单（三横线）、音量减（`−`）   |

共 12 个正面输入，无侧键。九字节报文（`01 00 00 XX 00 00 00 00 00`）与三字节报文（`02 LO HI`）使用独立状态组，互不误清。HID Usage Page 未从硬件描述表确认，保持 `original="false"`。
