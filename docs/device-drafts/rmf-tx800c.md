# RMF-TX800C 图稿交接

- 设备 ID：`rmf-tx800c`，内置和已有本机适配共用 kind `rmfTx800c`。型号由用户提供，补充照片确认品牌为 Sony。
- 图稿：[rmf-tx800c.svg](rmf-tx800c.svg)，`axonkey.device/1` 草稿，修订 3。根据正面和斜视照片绘制完整正面，按图稿规范省略品牌 Logo。没有可确认的侧键。
- 接入：[内置描述符](../../public/device-descriptors/rmf-tx800c.svg)使用本机「适配新设备」保存的 15 组 HID 按下/松开样本，另有一个由 Windows ATVV 控制事件驱动的麦克风热区。电源键只有外观，保留稳定 ID 供旧配置读取。

Windows 枚举名为 `SONY TV VRC 001`，BLE HID 服务 `0x1812`，硬件 ID 片段 `DEV_VID&02054C_PID&0DF7`。PnP ID 对应 USB 厂商/产品 ID `054C:0DF7`。GATT 截图记录厂商 `Sony Corporation`、型号字符串 `SMPL_CN`、固件 `22.01.01.022`；Windows 采集工具也观察到厂商拼法 `Sony_Corporation`。匹配不写入单台遥控器的蓝牙地址。

15 个常规键共用 ID `0x04`、总长 5 字节的报告；松开为 `04 00 00 00 00`。完整样本随内置 SVG 保存。用户用摄像头确认电源键发射红外，手动适配未观察到蓝牙 HID 报文，因此保留电源键图形，不提供蓝牙映射。

Windows 实测语音服务 `AB5E0001`：`AB5E0002` 写入，`AB5E0003` 音频通知，`AB5E0004` 控制通知。短按麦克风键收到 20 字节 `START_SEARCH`（`08` 后补零）。能力回复以 `0B 01 00 02 00 00 A0 00 00` 开头：ATVV 1.0、On-request、16 kHz ADPCM、每帧 160 字节。发送 `0C 00` 后收到 `04 00 02 00` 开头的开流通知；约 0.75 秒内收到 34 个 160 字节通知。发送 `0D 00` 后收到 `00` 关流通知并恢复两项订阅；只统计了长度，未保存录音。

Windows 开始菜单会在短按麦克风时弹出，尚未抓到触发它的系统输入。未观察到可用于按住录音的 HID 松开报文，内置描述符只声明点按开始和再次点按停止。整应用的虚拟麦克风输出尚待验证。已有同型号本机描述符优先于内置描述符；升级后如继续使用旧本机 SVG，会看不到新增的语音能力。

下表列出输入 ID 的后缀，完整 ID 统一以 `rmf-tx800c.` 开头。

| 正面位置（自上而下） | 热区及 ID 后缀 |
| --- | --- |
| 第一排 | 电视 `tv`、设置 `settings` |
| 第二排 | 输入源 `input`、数字键（123）`number` |
| 方向环与中央键 | 上 `up`、左 `left`、确认 `confirm`、右 `right`、下 `down` |
| 方向环下第一排 | 返回 `back`、主页 `home` |
| 方向环下第二排 | 静音 `mute`、麦克风 `voice`、菜单 `menu` |
| 底部音量摇杆 | 音量加 `volumeUp`、音量减 `volumeDown` |

「电视」右侧的圆形件是指示灯。指示灯及下方小孔均只保留外观。音量摇杆中间的符号属于同一键帽，未建立第三个输入。

Windows 接到该实例的 `START_SEARCH` 后，将一次按下和释放送入普通按键映射。它能绑定单击快捷键，虚拟麦克风驱动未连接时也能接收按键。驱动可用时，ATVV 仍按第一次开始、再次点按停止录音。真实长按时长和松手时机没有对应报文。

使用[热区检查页](device-hotzones.html)载入 SVG。开启热区后应显示 16 个按键，麦克风位于静音和菜单之间。分别点击方向环四个方向及中心，预期各自只选中一个输入。点击音量摇杆上下两半，应分别选中音量加和音量减。电源、指示灯、小孔和机身留白不可选中。Tab 可导航这 16 个键，Enter 或空格可选中按键。
