## 安装与首次使用

从 [GitHub Releases](https://github.com/leowzz/axonkey/releases) 下载对应系统的安装包。支持 Windows 11 64 位，以及 macOS 13 及以上版本（Apple Silicon / Intel）。

遥控器功能适用于小米蓝牙遥控器 2 Pro（RC003）。只使用鼠标映射时，无需连接遥控器。

### Windows

1. 安装并打开 Axonkey。
2. 使用遥控器时，先在系统蓝牙设置中配对 RC003，并按任意键唤醒它。
3. 添加 RC003 后，在它的设备工作区安装 Quarbor 输入驱动；需要语音时，再安装 VB-CABLE。
4. 按页面提示重新连接设备或重启 Windows。
5. 在“映射”中选择设备、按键和触发方式，设置目标行为，确认对应功能开关已开启。

驱动安装和卸载需要管理员权限，普通映射修改不需要重启。只使用鼠标映射时，不需要安装 Quarbor 驱动。

从旧版升级时，若引导提示清理 Interception 驱动或重连修复服务，按提示完成后再进入对应设备工作区安装当前驱动。手动安装、卸载命令见 [Windows 输入](WINDOWS_INPUT.md#手动安装驱动)。

### macOS

1. 打开 DMG，将 `Axonkey.app` 拖入“应用程序”，从该位置启动。
2. 使用遥控器时，在系统蓝牙设置中配对 RC003，并按任意键唤醒它。
3. 按引导授予“输入监控”和“辅助功能”权限。点击“开始授权”后，会出现置顶授权小窗。
4. 若系统权限列表中没有 Axonkey，点击小窗中的“在 Finder 中显示”，将高亮的应用拖入列表并打开开关，再重新检测。
5. 需要语音时安装 `MiRemoteV 2ch`；按键映射不需要额外输入驱动。
6. 在“映射”中配置目标行为，确认对应功能开关已开启。

鼠标映射同样需要输入监控和辅助功能权限。MiRemoteV 安装和卸载需要管理员授权，不需要重启系统。

不要长期直接运行 DMG 内的副本，以免权限指向临时路径。启动被拦截或授权后仍不可用时，见 [macOS 启动与授权排查](TROUBLESHOOTING.md#macos-无法打开应用或驱动安装包)。

## 遥控器映射

在“映射”左侧选择“小米遥控器”，点击遥控器图或按键列表中的目标按键，再分别配置单击、双击和长按行为。

全部 13 个按键均可配置，包括返回、音量、语音、电源、四向、确认、主页、菜单和 TV 键。可设置快捷键、媒体控制、鼠标操作、文本输入、打开应用或网站，也可以保留原按键或禁用。

多个步骤可以按顺序执行，例如“输入文本 → 等待 → 按 Enter”。内置“输入文本并回车”会在粘贴后等待 30 毫秒，再发送 Enter。

### 默认行为与触发

| RC003 按键 | 默认单击行为 |
| --- | --- |
| 语音键 | 右 Alt；macOS 显示为右 Opt |
| 电源键 | Escape |
| 其他按键 | 保留原按键 |

macOS 返回键默认是 Delete（退格），音量键保持系统音量调节及连续按压节奏。遥控器长按约 600 毫秒后首次触发，稍作等待后重复执行，松开停止。

这里的按键映射与语音转发相互独立。使用语音输入应用时，还需在该应用中选择正确的麦克风。

## 鼠标映射

在“映射”左侧选择“鼠标”，选择按键或滚动方向，再设置生效区域、触发方式和行为。鼠标初始保持系统原始操作；多个鼠标共用同一组配置。

### 生效区域

| 输入 | 可用区域 |
| --- | --- |
| 左键、右键 | 屏幕顶部、左侧、右侧边缘 |
| 中键（滚轮按下）、前进键、后退键 | 任意位置，或上述三个边缘 |
| 上下左右滚动 | 屏幕顶部、左侧、右侧边缘 |

支持多显示器；顶部角落优先按上边缘处理。边缘宽度在“设置 → 鼠标映射”中调整，Windows 按像素、macOS 按点计算。横向滚动需要鼠标或触控板支持水平滚动。

中键、前进键、后退键优先执行边缘规则，边缘未配置或步骤全部停用时，使用“任意位置”规则；两者都未配置时保持原始点击。

### 触发与原始操作

- 鼠标按键支持单击、双击和长按；滚动使用“滚动一次”。
- 单击在松开时执行；设置双击后，会等待 350 毫秒区分单击；长按 600 毫秒执行一次。
- 配置了映射的鼠标按键用于触发行为，不再提供原始拖拽。只配置双击或长按时，普通单击仍补发原始点击。
- 未配置的输入保持原始操作；滚动步骤全部停用时也保持原始输入。“禁用此触发方式”则拦截输入，不执行其他动作。
- 关闭鼠标功能开关可恢复系统原始操作，并取消尚未执行的映射。映射产生的滚轮或点击不会再次触发自身。

## 语音输入

按引导安装语音驱动后，在语音输入或录音应用中选择：

| 系统 | 麦克风 |
| --- | --- |
| Windows | `CABLE Output (VB-Audio Virtual Cable)` |
| macOS | `MiRemoteV 2ch` |

按住 RC003 语音键说话；可在 Axonkey 调节语音增益（−30 dB 至 +30 dB）。

Windows 的扬声器输出请保留真实耳机或扬声器，不要改成 `CABLE Input`。VB-CABLE 安装后需要重启 Windows，其使用条款见 [第三方说明](../THIRD_PARTY_NOTICES.md#vb-audio-vb-cable-pack45)。

**长时间连续说话仍可能延迟或丢失尾句，macOS 上已观察到此问题。** 详见 [语音问题排查](TROUBLESHOOTING.md#长时间说话时音频延迟)。

## 设置

普通设置自动保存。字段旁的问号可查看具体说明。

| 分类 | 可调整内容 |
| --- | --- |
| 启动设置 | 开机启动 |
| 系统权限 | 授权状态、打开授权设置、重新检测 |
| 遥控器映射 | 显示或收起顶部按键列表；收起后仍可点击遥控器图 |
| 鼠标映射 | 边缘宽度、滚动灵敏度、触发间隔和按键保持时间 |

### 鼠标参数

| 设置 | 默认值 | 范围与作用 |
| --- | --- | --- |
| 忽略滚动加速 | 开启 | 按事件次数计算触发量；100% 灵敏度下每条事件触发一次。不屏蔽惯性滚动。 |
| 滚动灵敏度 | 100% | 25%–400%。调高更容易触发，调低可减少误触。 |
| 垂直触发间隔 | 50 毫秒 | 0–10000 毫秒，上下滚动共用；0 表示不限制。 |
| 横向触发间隔 | 50 毫秒 | 0–10000 毫秒，左右滚动共用；0 表示不限制。 |
| 边缘生效宽度 | 8 | 1–100，顶部和左右边缘共用；Windows 为像素，macOS 为点。 |
| 按键保持时间 | 10 毫秒 | 0–1000 毫秒。快捷键漏识别时可尝试 50 毫秒；数值越大，连续触发越慢。 |

两个轴的触发间隔独立计时。例如设为 100 毫秒后，每次触发后的 100 毫秒内忽略同轴滚动，不会积累或补发；每次触发仍执行完整行为序列。灵敏度、滚动加速和触发间隔设置适用于三个屏幕边缘。

## 保存、备份与退出

- 映射修改自动保存并立即应用，配置保存在本机。可导出为 JSON 备份，再导入使用。
- 单配置导入导出使用当前设备格式 v2，完整备份使用当前备份格式 v2；旧版本、无版本号及缺少当前按键的文件不再支持导入。“恢复默认”只重置当前设备。
- 启动时发现旧配置会打开数据迁移向导，也可在 **设置 → 数据备份 → 数据迁移** 手动检查。支持早期单份映射、v1 共享配置，以及未经过向导处理的 v2 型号配置。
- 向导先检查已有的 RC003 小米遥控器：有匹配设备时，可选择覆盖其中一台的全部配置，也可新建；没有时直接新建。覆盖保留设备名称、物理绑定及其他设备设置。
- 点击“开始迁移”后，旧鼠标配置覆盖当前鼠标配置，旧小米遥控器配置写入所选或新建的遥控器实例。各配置名称、顺序和活动配置保留；新建或尚未绑定的设备随后打开物理设备绑定窗口。取消绑定仍会保留设备及迁移的配置，可稍后绑定。
- 不迁移时可选择“导出并删除”：确认后先将旧配置原始快照保存到系统“下载”目录（`axonkey-legacy-config-日期-时间.json`），文件写入成功后才删除应用中的旧配置，并显示保存路径。导出失败保留旧数据，可重试；浏览器预览不执行此操作。
- 迁移失败时保留旧数据，可重试；成功后清理迁移源，后续正常加载只读取当前格式。旧配置导出文件保留原始存储内容，不是当前格式的备份文件，普通备份导入不接受它。
- 关闭窗口后仍在 Windows 系统托盘或 macOS 菜单栏运行。需要停止时关闭对应功能开关，或从托盘／菜单栏选择“退出 Axonkey”。
- Axonkey 不需要账号，不上传映射、输入历史或诊断信息，也不提供云端同步。

目前不支持其他遥控器、普通键盘映射或 Linux，也不提供任意脚本和按应用切换配置。

## 更新与卸载

在“关于”中检查更新，点击“更新并重启”才会下载和安装。应用只检查当前主版本的更新，例如 v0 只更新到 v0；跨主版本或切换预发布版本，请从 [下载页](https://github.com/leowzz/axonkey/releases) 手动安装。

不同版本共用应用及配置目录，手动安装会覆盖已有应用；需要备份时先导出配置。更新机制与发布规则见 [自动更新](AUTO_UPDATE.md)。

Windows 卸载应用时会尝试移除 Quarbor 驱动绑定；驱动卸载失败或取消授权也不会阻止应用卸载。只想卸载输入驱动时，可使用应用内“卸载驱动”；手动操作见 [Windows 驱动卸载](WINDOWS_INPUT.md#卸载输入驱动)。
