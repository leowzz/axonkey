这是用于 macOS 遥控器语音问题排查的预发布版本。音频卡顿和累积延迟仍在调查中，本版本不宣称已解决。

### 新增与改进

- 在 **设置 → 设备与权限 → 遥控器信号** 中打开应用内监测窗口，左右对照蓝牙信号强度与语音收包速率，支持位置标记、暂停显示和导出读数。
- 改善 macOS 音频引擎恢复时的输出设备确认，降低切换声音设备后错误回传到扬声器的风险。
- 增加音频链路统计和按需启用的逐包诊断，方便区分蓝牙接收不足与应用输出异常。
- 提供 **软件拉伸补偿（实验）** 开关，默认关闭。该功能可能加重停顿或拖音，无法恢复缺失语音；遇到声音变差时请关闭。

### 已知问题与验证范围

当前 Mac 实机对照中，音频时长不足在 HCI 接收记录中已经存在，应用接收与对应 HCI 包匹配。尚不能区分遥控器发送、无线环境或控制器行为，也不能据此认定为 macOS 驱动故障。

本次本地验证覆盖前端构建、音频服务、队列与尾音处理、设置持久化和诊断记录。安装后仍需结合实际遥控器、位置和握法验证音频表现。

预发布版本需手动下载安装，不替换正式版 Latest，也不通过正式版自动更新通道推送。
