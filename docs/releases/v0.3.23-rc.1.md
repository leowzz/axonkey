这是用于 Windows RC003 重连验证的预发布版本，不替代当前正式版。

### 可选重连兼容修复

- 基于固定版本 `interception-driver-fix v0.5.2` 源码构建，应用运行时不下载修复程序。
- 新安装 Interception 驱动时会一并安装。已安装驱动的升级用户会先看到一次可选增强提示；可选择安装并重启，也可跳过后在 **设置 → 设备与权限 → 重连兼容修复** 中手动补装。
- 明确使用 **`lockdown=no`**，保留普通权限运行 Axonkey 的输入访问；此集成移除了设备 ACL 写入代码。
- 卸载修复服务后也必须 **重启 Windows**。卸载不会立即撤销本次启动中的对象链接，也不恢复旧版本曾改过的 ACL；卸载 Axonkey 前请先卸载修复。

### 验证范围

Windows 实机上的 RC003 断连、睡眠唤醒和多轮重连仍待用户验证。本版本不宣称 #25/#20 已解决，也不保证已失效设备免重启恢复。服务在执行后显示“已停止”属于一次性服务的正常行为，请结合退出码、日志和实际按键结果判断。

下载 Windows x64 安装包后，先确认原 Interception 驱动已安装并重启。启用修复、再次重启后，以普通权限运行 Axonkey，测试多次重连和睡眠唤醒。返回键/独立音量键的 Frida 增强通道仍需单独验证。
