# 0008. 剪贴板浮窗（`clipboardOverlay`）与紧凑列表 HUD

- 状态：`accepted`
- 日期：2026-11-24
- 关联 Issue：[leowzz/axonkey#107](https://github.com/leowzz/axonkey/issues/107)

## 背景

既有「快捷交互窗（`quickOverlay`）」允许用户为指定按键绑定一套静态配置文件，在屏幕顶层以设备键位图预览并一键触发常用动作或 Prompt。但在日常剪贴板历史选择场景中，条目随时变化且数量较多，把条目强行铺到设备键位图上不仅难以阅读完整列表，也让不同按键数量的设备体验不一致。

用户需要一个独立的简洁浮层 HUD（「剪贴板浮窗」）：按下绑定触发键后，在屏幕顶层无焦点抢占窗口中按**由新到旧**展示系统近期文本剪贴板列表，用物理设备的**上下方向键**（或鼠标侧键 / 边缘滚轮）切换选中项，按**确认键（OK）**立即关闭浮窗并粘贴（或仅写入剪贴板）到当前前台应用；按**返回键 / Esc** 或再次按下原触发键直接关闭。

## 决定

1. **独立的独占行为 `clipboardOverlay` 与兼容版本门槛**：
   - 新增行为类型 `clipboardOverlay`：`{ type: 'clipboardOverlay', action: 'paste' | 'copyText' }`（默认 `action = 'paste'`），作为对应触发方式（单击 / 双击 / 长按）的唯一独占行为使用。
   - `axonkey/2` 文本序列新增指令 `clipboard`（默认 `paste`）与 `clipboard copy`（`copyText`）；导出映射与全量备份时，包含 `clipboardOverlay` 的最低兼容版本提升至 **`1.9.21`**（`clipboardOverlayMinAppVersion`），并在多版本门槛共存时按语义化版本从高到低取最大值（`1.9.21 > 1.9.19 > 1.9.11 > 1.8.11`）。
   - `isCommunityShareableBehavior` 拒绝 `clipboardOverlay` 提交或加载至公开社区行为库，仅允许本地配置、CLI、备份导入导出与个人云同步。
2. **仅内存会话级剪贴板历史采集与隐私过滤**：
   - 新增 `clipboard_history` 后台轮询模块（400ms 检查系统变更计数 + 在唤起浮窗或读取历史瞬间立即同步），按最近使用顺序（MRU）由新到旧去重排列，最多保留 30 条非空白文本记录，单条上限 64 KiB。
   - 不持久化到磁盘、不上传云端，并在浮窗右上角提供一键清空入口（清空同时关闭当前剪贴板浮窗）。
   - 跨平台排除密码管理器与敏感标记内容：macOS 在读取前检查 `NSPasteboard.types`（过滤 `org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType`、`org.nspasteboard.AutoGeneratedType`、`com.agilebits.onepassword`）；Windows 检查 `ExcludeClipboardContentFromMonitorProcessing` 格式。
3. **紧凑列表 HUD（`420×460`）与方向键/OK 状态机**：
   - 复用非激活顶层原生窗口容器（`quick-overlay`），但渲染专用轻量列表组件 `ClipboardHud`（`420×460`）而非设备键位图。`QuickOverlaySession.clipboard`（`ClipboardOverlayState { action, entries, selectedIndex }`）承载由新到旧的条目和当前高亮索引；后端提供 `set_clipboard_selected` 同步选中状态、`select_clipboard_overlay_item` 处理鼠标直接点击条目执行并退出。
   - `QuickMode` 针对剪贴板会话运行独立导航状态机（`SessionKind::Clipboard`）：
     - 基于描述符 `icon` / `kind` / 名称及鼠标控制项分类 `ClipboardNav`（`Up` / `Down` / `Confirm` / `Cancel`），自动忽略摇杆轴（`kind="axis"`）。
     - `Up` / `Down` 限幅移动 `selected_index`（支持按住 400ms 后 110ms 连发）并通过事件实时驱动 HUD 高亮及滚动对齐；小鼠中键/遥控器 Confirm/OK 确认执行当前高亮条目（`Paste` 或 `CopyText`）并退出模式；返回/Esc/再次按下原触发键立即关闭。

## 主要取舍及影响

- **取舍：独立紧凑列表 HUD vs. 把剪贴板历史平铺到设备键位图**
  - 平铺到设备键位图受限于遥控器/鼠标按键数量和键帽宽度，多行文本截断严重且难以浏览多达 30 条记录。改用固定窄幅 `420×460` 垂直列表 + 上下切换 + OK 确认后，无论遥控器还是鼠标都能一致、完整地浏览与选取所有历史记录，前端也无需为剪贴板条目构造伪造设备行为字典。
- **取舍：复用 `quick-overlay` 非激活原生面板 vs. 新建独立 OS 窗口**
  - `quick-overlay` 已验证支持 macOS `NSPanel`（`NSWindowStyleMaskNonactivatingPanel` + 全屏辅助 Space）与 Windows `WS_EX_NOACTIVATE` 且不抢占前台应用焦点；根据 `session.clipboard` 动态切换窗口尺寸（`420×460` vs `880×660`）与 React 视图即可零额外冷启动成本上线。
- **取舍：仅内存保存 vs. 持久化 SQLite 历史**
  - 系统剪贴板常包含临时令牌、对话片段或敏感内容。选择纯内存 + 密码管理器标记过滤 + 一键清空，大幅降低隐私泄露风险与迁移复杂度。
