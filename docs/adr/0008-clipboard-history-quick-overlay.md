# 0008. 剪贴板交互窗（`clipboardOverlay`）与动态按键平铺

- 状态：`accepted`
- 日期：2026-11-23
- 关联 Issue：[leowzz/axonkey#107](https://github.com/leowzz/axonkey/issues/107)

## 背景

既有「快捷交互窗（`quickOverlay`）」允许用户为指定按键绑定一套静态配置文件，在屏幕顶层预览并一键触发常用动作或 Prompt。但在日常高频复制粘贴、代码/文本片段搬运场景中，剪贴板内容随时变化，无法预先写死在静态配置中。

用户需要一种与快捷交互窗操作方式一致的「剪贴板交互窗」：按下指定触发键后，系统将近期剪贴板历史条目动态平铺到同一设备的其余可用物理按键上并在顶层浮层展示；按下任意已铺按键立即退出模式并直接粘贴（或仅写入剪贴板）到当前前台应用，再次按下原触发键或未映射键则安全退出模式。

## 决定

1. **独立的独占行为 `clipboardOverlay` 与兼容版本门槛**：
   - 新增行为类型 `clipboardOverlay`：`{ type: 'clipboardOverlay', action: 'paste' | 'copyText' }`（默认 `action = 'paste'`），作为对应触发方式（单击 / 双击 / 长按）的唯一独占行为使用。
   - `axonkey/2` 文本序列新增指令 `clipboard`（默认 `paste`）与 `clipboard copy`（`copyText`）；导出映射与全量备份时，包含 `clipboardOverlay` 的最低兼容版本提升至 **`1.9.21`**（`clipboardOverlayMinAppVersion`），并在多版本门槛共存时按语义化版本从高到低取最大值（`1.9.21 > 1.9.19 > 1.9.11 > 1.8.11`）。
   - `isCommunityShareableBehavior` 拒绝 `clipboardOverlay` 提交或加载至公开社区行为库，仅允许本地配置、CLI、备份导入导出与个人云同步。
2. **仅内存会话级剪贴板历史采集与隐私过滤**：
   - 新增 `clipboard_history` 后台轮询模块（400ms 检查系统变更计数 + 在唤起交互窗或读取历史瞬间立即同步），按最近使用顺序（MRU）去重，最多保留 30 条非空白文本记录，单条上限 64 KiB。
   - 不持久化到磁盘、不上传云端，并在浮层提供一键清空入口（清空同时关闭当前剪贴板交互窗）。
   - 跨平台排除密码管理器与敏感标记内容：macOS 在读取前检查 `NSPasteboard.types`（过滤 `org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType`、`org.nspasteboard.AutoGeneratedType`、`com.agilebits.onepassword`）；Windows 检查 `ExcludeClipboardContentFromMonitorProcessing` 格式。
3. **跨设备动态铺键与 `QuickMode` 复用**：
   - 沿用现有 `QuickMode` 单次模态状态机与非激活顶层浮层（`quick-overlay`），无需新增平行窗口或独立输入拦截链路。
   - **目标按键顺序**：物理设备按 SVG 描述符 `ak:input` 的 `order` 属性（未标注则按声明顺序）筛选非 `pending`、非 `axis` 的输入，剔除当前触发键后顺序分配给近期剪贴板条目；系统鼠标按当前触发作用域（边缘触发对应边缘全部控制项，全局触发对应全局侧键与中键）剔除触发键后顺序分配。
   - 每个分配按键生成单步 `click` 动作（`paste` 或 `copyText`），由原有非激活浮层与前后台输入服务直接执行并保持前台应用焦点不丢失。

## 主要取舍及影响

- **取舍：独立 `clipboardOverlay` 行为 vs. 在静态 `quickOverlay` 配置文件中塞入动态占位符**
  - 静态快捷配置依赖用户逐键编辑与持久化按键字典，无法在运行时按设备键位顺序把可变数量的剪贴板历史动态铺满其他按键。引入独立行为并在进入 `QuickMode` 时动态构造临时 `QuickProfileConfig`，既保持 `QuickProfile` 数据纯净，又 100% 复用 `QuickMode` 与非激活浮层渲染管线。
- **取舍：仅内存保存 vs. 持久化 SQLite 历史**
  - 系统剪贴板常包含临时令牌、对话片段或敏感内容。选择纯内存 + 密码管理器标记过滤 + 一键清空，大幅降低隐私泄露风险与迁移复杂度；代价是软件重启后历史列表从当前剪贴板重新积累。
- **取舍：按设备 `order` 顺序铺键 vs. 仅挑少数固定键**
  - 按描述符既有的物理视觉从上到下/从左到右 `order`（并跳过摇杆轴和触发键本身）铺键，能自动适配任意内置与自定义 SVG 设备（遥控器、小键盘、手柄、鼠标），无需为不同设备编写硬编码映射表。
